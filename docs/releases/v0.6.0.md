# Adaptive Agent Orchestrator v0.6.0

## 中文

v0.6.0 将 Skill 从“多 Agent 编排器”推进为适用于研究、开发、写作、
分析、创意和运营任务的工作所有权与上下文效率层。

主要变化：

- 主 Agent既是唯一编排者，也是核心生产者；
- 任务入口和关键事件点动态判断工作归属，不创建常驻调度 Agent；
- 第一波允许0–2个Worker，两个必须同时就绪且上下文完全分离；
- 原生subagent默认不继承完整聊天，只读取紧凑任务包和稳定引用；
- 专业Worker可拥有边界明确的章节、模块、调查、数据集或设计面；
- 长期项目可选保存可追溯的决策、事实、接口和风险，普通任务不建知识库；
- 保留v0.5.1的线程实体核对、结果回执、容量隔离和模型升级授权。

验证：

- 22个PowerShell脚本解析通过；
- 472项断言通过；
- 48个故意构造的非法计划被正确拒绝；
- Skill结构校验通过。

## English

v0.6.0 evolves the Skill from a multi-agent orchestrator into a general work
ownership and context-efficiency layer for research, coding, writing, analysis,
creative, and operational tasks.

Highlights:

- the main agent is both the sole orchestrator and a core producer;
- ownership is re-evaluated at meaningful task events without a Router Agent;
- wave 1 contains zero to two Workers, with two requiring disjoint context;
- native subagents start without full conversation inheritance by default;
- specialists may own bounded artifacts across any domain;
- durable projects may use a sourced lightweight knowledge catalog;
- v0.5.1 reconciliation, result receipts, capacity isolation, and escalation
  authorization remain intact.

Validation:

- all 22 PowerShell scripts parse;
- 472 self-test assertions pass;
- 48 intentional invalid plans are rejected;
- the Skill structure validator passes.
