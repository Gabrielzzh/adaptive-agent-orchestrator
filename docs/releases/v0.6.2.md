# Adaptive Agent Orchestrator v0.6.2

## 中文

v0.6.2 是格式兼容、控制面保护和上下文复用方面的加固版本。

### 修复

- 修复示例计划中的尾随逗号。该文件此前可被 PowerShell 的宽容解析器
  接受，但不是合法的 RFC 8259 JSON。
- 自测现在使用 PowerShell 7 自带的 `System.Text.Json` 严格解析所有引用
  JSON，不再用正则表达式代替完整 JSON 解析。

### 加固

- 所有计划节点均不得把 `write_scope` 直接指向 `.orchestrator/`。项目知识
  必须由主 Agent 通过 `Manage-ProjectKnowledge.ps1` 管理。
- 新增真实 Windows Junction fixture，验证 Worker 输入穿越 reparse point
  时会被拒绝。符号链接 fixture 在权限不足时明确跳过。
- 小型任务保持零 Worker；有界独立验证至多使用一个 Worker；只有具有独立
  交付物和低上下文重叠的广度任务才渐进扩张。
- 已采纳的 Worker 原始回复不会再次注入后续任务包、handoff 或压缩恢复
  状态。已被主 Agent 读取的当前模型上下文无法被追溯删除。

### 验证

- 22 个 PowerShell 脚本解析通过；
- 491 项自测断言通过；
- 50 个故意构造的非法计划被正确拒绝；
- 7 个引用 JSON 通过严格解析；
- Skill Creator 校验通过；
- Windows Junction/reparse-point 实体测试通过。

尚未执行真实 Codex 后台任务 materialization forward-test，也尚未发布
GitHub。

## English

v0.6.2 hardens format compatibility, control-plane ownership, and context
reuse.

### Fixes

- Remove the trailing comma from the example plan. PowerShell's tolerant
  parser accepted it, but it was not valid RFC 8259 JSON.
- Parse every bundled reference JSON with PowerShell 7's `System.Text.Json`
  during self-test instead of treating a regular expression as a complete JSON
  validator.

### Hardening

- No plan node may directly claim a `write_scope` under `.orchestrator/`.
  Project knowledge is managed by the main agent through
  `Manage-ProjectKnowledge.ps1`.
- Add a real Windows Junction fixture and verify that Worker inputs crossing a
  reparse point are rejected. The symbolic-link fixture reports a skip when
  privileges do not permit link creation.
- Keep small work at zero Workers, bounded independent verification at no more
  than one Worker, and expand progressively only for breadth with independent
  deliverables and low context overlap.
- Do not re-inject adopted raw Worker output into later packets, handoffs, or
  compaction recovery state. Content already read by the main agent cannot be
  retroactively removed from the current model context.

### Validation

- all 22 PowerShell scripts parse;
- 491 self-test assertions pass;
- 50 intentionally invalid plans are rejected;
- all 7 reference JSON files parse strictly;
- Skill Creator validation passes;
- the Windows Junction/reparse-point fixture passes.

A live Codex background-task materialization forward-test and GitHub release
have not been performed.
