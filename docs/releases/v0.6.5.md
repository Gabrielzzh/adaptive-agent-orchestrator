# v0.6.5 candidate / 候选版

Status: validated local candidate; not yet published.

## 中文

v0.6.5 收紧任务创建核对，并完成一批 PowerShell 跨平台修复。

### 任务创建安全

- 创建调用明确返回任务 ID 时，即使 `list_threads` 暂时看不到该任务，也
  不能判定 `no_match`，更不能自动创建替代任务。
- 主 Agent 应优先直接读取返回的任务 ID，并核对完整 activation markers。
- 对 error、timeout 或 unknown 创建结果，使用 40 秒临时安全下限；证据仍
  不充分时保持 `unknown`。
- 40 秒高于当前一次前向测试中“19 秒仍不可见、37 秒可见”的观测，但不是
  统计校准结果，后续仍需多个真实样本验证。

### 跨平台路径

- 项目知识、activation receipt、模型缓存、测试产物路径不再依赖 Windows
  反斜杠。
- Writer 父子路径重叠检查使用当前平台的目录分隔符。
- 自测扫描常见的 `Join-Path` Windows-only 路径写法。

### 运行测量

新增 `Measure-OrchestrationRun.ps1`，只读汇总 durable run 的启动次数、
实体 Worker、核对延迟、结果 receipt、重复输入引用和任务包字符数。它只
用于开发评估与事后诊断，不预测 Token，不要求用户设置预算。

### 验证

- 25 个 PowerShell 7 脚本解析通过；
- 508 项自测断言通过；
- 50 个故意构造的非法计划被正确拒绝；
- Skill Creator 校验通过。

Linux PowerShell 7 尚未安装，因此 Linux 执行验证仍未完成。

## English

v0.6.5 hardens task-creation reconciliation and fixes several
PowerShell portability issues.

### Task-creation safety

- A successful creation call with a returned task ID cannot become `no_match`
  merely because `list_threads` visibility is delayed.
- The controller should read the returned task ID directly and verify its full
  activation markers.
- Error, timeout, and unknown creation results use a provisional forty-second
  safety floor; insufficient evidence remains `unknown`.
- Forty seconds exceeds the current single observation of absence at nineteen
  seconds and visibility by thirty-seven seconds. It is not presented as
  statistical calibration.

### Cross-platform paths

- Project knowledge, activation receipts, model cache, and test artifact paths
  no longer depend on Windows-only separators.
- Parent/child writer overlap uses the active platform separator.
- Self-test scans common `Join-Path` Windows-only path literals.

### Run measurement

`Measure-OrchestrationRun.ps1` provides a read-only summary of durable-run
launches, materialized Workers, reconciliation delays, result receipts,
repeated input references, and packet character counts. It is evaluation and
diagnostic tooling, not a Token estimator or user budget system.

### Validation

- all 25 PowerShell 7 scripts parse;
- 508 self-test assertions pass;
- 50 intentional invalid plans are rejected;
- Skill Creator validation passes.

Linux PowerShell 7 is not installed, so Linux execution remains unverified.
