## 中文主帖

Adaptive Agent Orchestrator v0.7.0 正式发布 🚀

不是让 Agent 更多，而是让协作更聪明：

• 主 Agent 持续生产  
• 按需选择 subagent / durable task  
• 只传必要上下文  
• 防止重复创建，结果可验收  
• Luna / Sol 静态路由，不做前置模型测试
